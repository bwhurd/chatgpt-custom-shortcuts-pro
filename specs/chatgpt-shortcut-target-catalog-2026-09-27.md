# Live ChatGPT shortcut-target catalog — 2026-09-27

## Scope and reading guide

- The active inventory is 64 registered target descriptors used by 52 shortcut-action metadata entries in extension/shared/shortcut-action-metadata.js, plus three auxiliary runtime targets: native code-block Copy and the dynamic model-profile Speed/Reset utilities. Retired descriptor references are listed separately and do not count toward the registered inventory.
- The code column records the registry locator (test ID, selector list, SVG token, menu chain, or manual/dynamic target). Runtime implementations and their fallbacks remain in extension/content.js.
- The initial DOM comparison was read-only. The 2026-09-27 live audit used disposable audit-owned conversations and the loaded unpacked extension; its outcomes are recorded below and are not user acceptance.
- “Not observed” means the required menu, dialog, or mode was not open in this one captured state; it does not mean the target is absent. The state column identifies what must be exposed for a later manual review.
- The catalog is a handoff checklist, not a validation report. Completed repair items are marked “repaired; ready for your manual review,” never “verified.”
